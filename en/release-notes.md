## AI Service > Text to Speech > Release Notes { #ai-service-text-to-speech-release-notes }

<a id="july-7-2026"></a>
### July 7, 2026 { #july-7-2026 }

* Changed the domain
* API v1.1 released
  * Added API using User Access Key token authentication.
  * For more information on issuing and using User Access Key tokens, see the [User Access Key Token](/nhncloud/en/public-api/user-access-key-token).

<a id="june-9-2026"></a>
### June 9, 2026 { #june-9-2026 }

* Changed supported languages
    * (Previous) Korean, Japanese, Chinese, English → (Updated) Korean
* Changed supported options
    * (Previous) Gender, pitch, speed, volume, tone, intonation → (Updated) Gender, speed
* Added new voice
    * Female2

<a id="september-26-2023"></a>
### September 26, 2023 { #september-26-2023 }

* Added supported languages
    * English (Female), Japanese (Male), Chinese (Male)
* Improved voice quality
    * Improved voice quality when selecting Korean to synthesize the voice in English
* Bug Fixes
    * Fixed an issue where, when selecting Chinese, voice synthesis in another language would fail
    
<a id="april-11-2023"></a>
### April 11, 2023 { #april-11-2023 }

* Added supported languages
    * Chinese (Female)
* Improved voice quality

<a id="february-28-2023"></a>
### February 28, 2023 { #february-28-2023 }

* Improved speech synthesis speed
* Added supported languages
    * English (Male), Japanese (Female)
* Improved the console UI
    * Removed guide message at the top
    * Added tooltip

<a id="june-30-2022"></a>
### June 30, 2022 { #june-30-2022 }

* Added 'Voice Emotion' to detailed settings for voice synthesis
* Changed the 'Female' voice among 'Voice Type'
* Improved the preprocessing for speech synthesis

<a id="january-25-2022"></a>
### January 25, 2022 { #january-25-2022 }

* Text to Speech service released
