## AI Service > Text to Speech > リリースノート { #ai-service-text-to-speech-release-notes }

<a id="july-7-2026"></a>
### 2026. 07. 07. { #july-7-2026 }

* ドメイン変更
* API v1.1リリース
  * User Access Keyトークン認証を使用するAPIが追加されました。
  * User Access Keyトークンの発行及び使用に関する詳細は、[User Access Keyトークン](/nhncloud/ja/public-api/user-access-key-token)を参照してください。

<a id="june-9-2026"></a>
### 2026. 06. 09. { #june-9-2026 }

* サポート言語の変更
  * (従来) 韓国語、日本語、中国語、英語 → (変更) 韓国語
* サポートオプションの変更
  * (従来) 性別、ピッチ、速度、音量、トーン、イントネーション → (変更) 性別、速度
* 新規音声の追加
  * 女性2

<a id="september-26-2023"></a>
### 2023. 09. 26. { #september-26-2023 }

* サポート言語の追加
    * 英語(女性)、日本語(男性)、中国語(男性)
* 音声の品質改善
    * 韓国語を選択した後、英語で音声を合成した際の音声品質が向上
* バグ修正
    * 中国語を選択した後、他の言語で音声を合成した際に失敗するエラーを修正
